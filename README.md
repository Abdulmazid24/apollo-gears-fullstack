# Apollo Gears - Car Rental & Bidding Platform

A full-stack car rental & bidding platform built with Next.js 16, React 19, Express.js, TypeScript, PostgreSQL, Prisma ORM, and Stripe.

## Project Structure

- `backend`: Express.js + Prisma ORM + PostgreSQL API server
- `frontend`: Next.js 16 (App Router) + Tailwind CSS + shadcn/ui client application

## Tech Stack

- **Frontend**: Next.js 16, React 19, TypeScript, Tailwind CSS v4, shadcn/ui, Lucide Icons
- **Backend**: Express.js, TypeScript, Prisma ORM, PostgreSQL, Zod, JWT, Stripe
